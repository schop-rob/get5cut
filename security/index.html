Security

Data handling summary for IT and procurement review. Last updated 4 October 2026, app version 1.2.5.

Your recordings never leave your iPhone. 5cut cuts, transcribes and makes notes on the device. There is no 5cut server, no account system and no cloud processing. A recording, transcript or export leaves the device only when the user exports it to a place that the user chooses.

Why you do not need a DPA

A data processing agreement controls how a processor handles personal data for a controller. 5cut never receives your data, so there is no processing relationship to control. The developer cannot access, see or keep any recording, transcript or export. This is not a policy promise. No system exists that can receive the data.

If your process needs a signed statement instead of a policy page, contact us. We will send you one.

Where the data is

  • The app keeps imported and recorded media, drafts and transcripts in its iOS sandbox container on the device.
  • The app writes nothing to shared storage until the user exports it.
  • 5cut excludes imported files and the recordings that it makes from iCloud device backups.
  • Your MDM policy, remote wipe and device encryption apply to this container, as to any other app.

Encryption at rest, in detail

Two layers apply. First, every modern iPhone encrypts its storage in hardware, with a key that is part of the chip. This protects the data if someone removes the flash memory from the device. Second, iOS Data Protection gives each file its own key. A class key wraps this file key, and iOS makes the class key partly from the device passcode. 5cut uses these classes:

  • Complete protection for the project database. The database is unreadable while the device is locked.
  • Complete until first user authentication for imported and recorded media. The media is unreadable until the user unlocks the device one time after a restart. This is also the iOS default for app data.

There are two limits. First, Data Protection gets its strength from the device passcode. Without a passcode, only the hardware layer protects the data. For this reason, enforce a passcode policy through MDM.

Second, Data Protection protects a lost or stolen device. It does not protect a device that an attacker holds while it is unlocked. When a user exports a file to Photos or Files, the protection of that destination applies, not the protection of 5cut.

Speech, voice detection and AI notes

Every speech engine runs on the device, with local models:

  • Apple SpeechAnalyzer (iOS 26 or later), with the on-device speech assets of Apple.
  • WhisperKit, Parakeet (Ultra, Lite, Phonon-2) and Moonshine, as local models.
  • Speaker identification uses a local Sortformer model.
  • Voice detection for silence removal uses Silero VAD. This model is part of the app and never downloads.
  • AI notes use Apple Intelligence on the device, or an optional local model (Qwen3 0.6B or Gemma 4 E2B) that runs with LiteRT-LM.

Earlier versions had a fallback to the server-side speech recognition of Apple, for languages and devices without on-device support. Version 1.2.5 removed that path. The engine that was able to reach a server is gone. Every engine above runs on the device.

The app declares the iOS Speech Recognition permission. Apple requires this declaration from each app that links its Speech framework. 5cut links the framework to use the on-device transcriber. The declaration shows which API an app uses. It does not show where the audio goes.

To check where the audio goes, do one of these tests:

  • Download a transcription model one time, then turn on Airplane Mode. Transcribe a recording. 5cut works the same.
  • Watch the traffic of the device through a proxy while 5cut transcribes.

Network activity

The app sends requests to the network in two cases only. Neither case sends user content:

  • Model downloads. The first time a user selects an engine or an optional AI model, the app downloads the model from Hugging Face or its mirror. Apple SpeechAnalyzer gets its assets from Apple. Each download comes to the device one time.
  • Video import from a URL. When a user imports a video from a URL, the app downloads that URL.

The app has no SDKs for analytics, crash reports, attribution or ads. The internal analytics helper of the app writes logs in debug builds only. In App Store builds, it does nothing.

Third-party components

All components are open source and run on the device. They do inference or utility work only. None of them sends user data:

  • WhisperKit (Argmax): local speech recognition
  • FluidAudio (FluidInference): local speech recognition and speaker identification
  • Moonshine (Moonshine AI): local streaming speech recognition
  • LiteRT-LM (Google): runs the optional local AI models for notes
  • Silero VAD: local voice detection, part of the app
  • swift-argument-parser (Apple): utilities

Permissions that the app requests

  • Microphone: only while the user records in the app.
  • Photo Library: to select videos to edit and to save the exports that the user requests.
  • Files: when the user imports a file.
  • Speech Recognition: Apple requires it for its on-device speech engine. It gives access to the local recognizer, not to a network service.

The app does not request contacts, location, calendar or tracking permissions.

Only the user exports data

Users can export transcripts and notes to Apple Notes, Markdown, Anki, Notion or Obsidian, and video to Photos or Files. Each export is a user action with the normal iOS share sheet. If your organization limits destinations, your MDM and Managed Open In policies control this. 5cut adds no separate channel.

What we do not claim

5cut is a small independent app. These are its limits.

There is no SOC 2 report, no ISO 27001 certification and no third-party penetration test. These reports show how an organization controls the customer data that it receives. 5cut receives no customer data, so it does not create this risk.

There is also no admin console, no central policy enforcement and no audit log, because there is no account system for them. Apple Business Manager and your MDM handle all deployment and control.

Deployment

5cut is in the App Store. You can deploy it to managed devices through Apple Business Manager and your MDM. Apple does not sell in-app purchases in volume. For a license for your whole organization, contact us about a custom build with the paid features already active.
