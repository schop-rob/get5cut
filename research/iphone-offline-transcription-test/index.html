Which 5cut engine handles accented lecture speech offline?

This page holds the protocol for a repeatable test. The test compares Apple Speech, WhisperKit, Parakeet and Phonon-2 in 5cut on one iPhone.

Status: the protocol is ready. Recordings and results are pending.

Pre-registered question: Which of these four 5cut engines can transcribe accented lecture speech without a network connection, and how accurate are they?

Test material

The developer records two original samples in lecture style, with the same iPhone microphone in normal indoor conditions. Each sample is about five minutes long. Each sample comes with a reference transcript that the developer checked by hand.

Controls

  1. Use one iPhone, one iOS build, the same microphone position and the same source files for every engine.
  2. Download the necessary models before the test. Write down the device, iOS, 5cut, engine and model versions.
  3. Turn on Airplane Mode before each transcription run. Make sure that Wi-Fi and Bluetooth are off.
  4. Start each run from a new import. Do not correct an engine output by hand.
  5. Export the raw text. Measure the transcription time with the same timing rule each time.
  6. Publish failures and weak results. A failed run, or a run that needs the network, is a result. It is not a reason to omit the engine.

How word error rate is calculated

Word error rate (WER) measures the errors in a transcript. It is the minimum number of substitutions, deletions and insertions that change the engine output into the reference transcript. Divide this number by the number of words in the reference.

WER = (substitutions + deletions + insertions) / reference words

The repository contains a calculator with no dependencies at growth_engine/benchmark/compute_wer.py. Before we publish, we must list the normalization rules and the exact command here. Then another person can reproduce each number.

Required publication bundle

  • Both original audio files and the reference transcripts that the developer checked by hand.
  • All eight raw engine outputs: four engines × two samples.
  • WER results, edit counts, elapsed times and all failed runs.
  • Device, iOS, 5cut, engine and model versions, and the test date.
  • Normalization rules and the exact calculator command.
  • A section about the limits of the test. It must separate this small test with one speaker from a general claim about accuracy.

Limitations to publish with the results

This test has two samples, one speaker and one device. It is not a population benchmark. WER can change with the microphone, background noise, technical words, accents, languages, segmentation, normalization of punctuation, model versions and device hardware. The results will describe these files and this setup only.

Publication gate

Remove noindex and add this page to the sitemap and llms.txt only when the page links every required file and no cell says Pending. Run the test again after a large engine change or after six months, whichever comes later.
